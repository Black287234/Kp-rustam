# Заявки на служебный транспорт (TransportOrders)

Курсовая работа по МДК.01.01 «Разработка программных модулей», тема 17:
«Проектирование и разработка модуля заявок на использование служебного транспорта».
Выполнил: Лыхин Рустам Владимирович, группа ИСиП-23/1. Руководитель: Крючков Виталий Владимирович.

**Текущее состояние: этап 1 — постановка задачи и первый запуск.**

## Что потребуется
- .NET SDK 10 (проверка: `dotnet --version`, версия должна начинаться с `10.`);
- любой браузер.

## Как запустить
```
dotnet run --project src/TransportOrders.Web
```
После сообщения `Now listening on: http://localhost:5113` открыть в браузере http://localhost:5113.
Остановка — `Ctrl+C`. В Visual Studio 2026 открыть `TransportOrders.slnx` и нажать F5.

## Что можно проверить
| Адрес | Что должно получиться |
|---|---|
| `/Cars` | автопарк из 8 учебных автомобилей |
| `/Cars/Card/3` | карточка микроавтобуса Hyundai H-1, госномер Е771ТН 86 |
| `/Cars/Card/999` | страница «Запись не найдена», код 404 |
| `/api/cars` | список автомобилей в JSON |
| `/api/cars/999` | `{"message":"Автомобиль № 999 не найден"}`, код 404 |

## Где хранятся данные
На этапе 1 автомобили задаются в коде (`Data/MemoryCarSource.cs`) и при перезапуске возвращаются к исходным.
Постоянное хранение в SQLite появится на этапе 2.
